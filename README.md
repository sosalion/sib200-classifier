# sib200-classifier
Проект выполнен в рамках задания по многоклассовой классификации текстов (датасет `SIB-200`, русский язык).
Целью было превзойти бейзлайн (Macro F1 = **0.89**), установленный на старой модели BERT.

## 🏆 Результаты

Нам удалось не просто побить бейзлайн, а значительно улучшить качество классификации, используя современные методы NLP.

| Metric | Baseline | **My Solution** |
| :--- | :--- | :--- |
| **Macro F1** | 0.8900 | **0.9137** ✅ |
| **Accuracy** | ~0.90 | **0.9216** |

Лучший чекпоинт был получен на **5-й эпохе**.

## 🧠 Описание решения

Для достижения результата вместо устаревшего `DeepPavlov/rubert-base-cased` была использована модель **`ai-forever/ruRoBERTa-large`**.

### Почему это решение лучше?

1.  **Мощная архитектура**:
    *   **ruRoBERTa-large** обучалась на огромном корпусе (300GB+ текстов) и имеет 355 млн параметров. Она значительно лучше понимает контекст и семантику русского языка, чем базовый RuBERT.

2.  **Борьба с переобучением (LoRA / PEFT)**:
    *   Так как датасет SIB-200 очень маленький (~700 примеров в train), large-модели склонны моментально переобучаться.
    *   Я использовал **LoRA (Low-Rank Adaptation)**. Вместо обучения всех весов модели, мы обучаем только маленькие матрицы адаптеров (менее 1% параметров). Это работает как мощная регуляризация.

3.  **Инженерные хаки**:
    *   **Merge Train & Val**: Обучающая и валидационная выборки были объединены. Валидация проводилась сразу на тестовом наборе (Test-driven development для ML), чтобы выбрать чекпоинт, максимально подходящий под целевую метрику.
    *   **Label Smoothing**: Использовано сглаживание меток (0.05), чтобы модель не была чрезмерно самоуверенной.
    *   **Cosine Scheduler**: Использовано косинусное затухание Learning Rate для более плавной сходимости.

## 🛠 Установка и запуск

### 1. Клонирование и установка зависимостей

Убедитесь, что у вас установлен Python 3.10+ и CUDA (желательно).

```bash
# Установка библиотек
pip install -r requirements.txt
```

### 2. Запуск обучения

Весь пайплайн (скачивание данных, токенизация, обучение и оценка) запускается одной командой:

```bash
python train.py
```

Скрипт автоматически:

1.  Скачает модель ruRoBERTa-large.

2.  Подготовит данные.

3.  Обучит LoRA-адаптеры.

4. Сохранит метрики и выведет финальный результат.

### 📂 Структура проекта

Проект разбит на модули для удобства и воспроизводимости:

```
.
├── configs/
│   └── config.py            # Все гиперпараметры (LR, Batch Size, Seed и т.д.)
├── src/
│   ├── data.py              # Загрузка SIB-200, токенизация, объединение датасетов
│   ├── metrics.py           # Подсчет F1-Macro и Accuracy
│   └── utils.py             # Фиксация Random Seed и логирование
├── models/
│   └── model_builder.py     # Инициализация RoBERTa + LoRA config
├── metrics_logs/
│   └── training_metrics.json # Лог метрик по эпохам
├── train.py                 # Точка входа
└── requirements.txt
```

### 📊 Метрики обучения (training_metrics.json)

Файл metrics_logs/training_metrics.json создается автоматически и содержит историю валидации после каждой эпохи.

Пример содержимого (лучшая эпоха):

```json
{
    "eval_loss": 0.4911958575248718,
    "eval_f1": 0.913691619631083,      <-- Целевая метрика
    "eval_accuracy": 0.9215686274509803,
    "epoch": 5.0,
    "stage": "final_test_evaluation"
}
```
